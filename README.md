# 상가업소 검색 지도

## 개요
소상공인시장진흥공단의 `상가(상권)정보` CSV를 브라우저에서 불러와 상호명 부분 검색, 지도 표시, 결과 다운로드를 수행하는 정적 웹페이지입니다.

## 실행 방법
1. `index.html` 파일을 다운로드합니다.
2. 인터넷에 연결된 상태에서 Chrome 또는 Edge로 파일을 엽니다. Leaflet, PapaParse 및 OpenStreetMap 타일을 온라인에서 불러옵니다.
3. 공공데이터포털에서 받은 CSV를 업로드합니다.
4. 상호명을 입력하고 `검색하기`를 누릅니다.
5. `결과 CSV 저장` 또는 `결과 GeoJSON 저장`을 누릅니다.

## 필수 컬럼
CSV 헤더에 다음 이름이 정확히 있어야 합니다: `상호명`, `지점명`, `도로명`, `경도`, `위도`.
공공데이터 원본의 주소 컬럼이 `도로명주소`로 되어 있다면, CSV에서 해당 열 이름을 `도로명`으로 변경하거나 HTML의 필수 컬럼 및 표시 코드를 함께 수정하세요. 열 이름 앞뒤 공백과 UTF-8 BOM은 자동 정리합니다.

## 주요 기능과 처리 기준
- 상호명에 검색어가 포함된 행을 대소문자 구분 없이 추출합니다.
- 위도·경도가 유효한 행만 지도 마커와 GeoJSON에 포함합니다.
- 결과 표는 최대 500건까지만 표시하고, 지도 마커는 성능을 위해 최대 5,000개까지만 그립니다. 검색 결과 다운로드에는 전체 일치 행이 포함됩니다.
- CSV 저장 시 UTF-8 BOM을 추가해 Excel 한글 호환성을 높입니다.
- CSV는 서버로 전송되지 않고 브라우저에서 처리됩니다.
- CSV 파싱에 PapaParse의 worker 옵션을 사용하지만, 대용량 파일은 브라우저 메모리를 많이 사용할 수 있습니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다.
2. `index.html`을 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. 배포 소스를 `Deploy from a branch`, 브랜치는 `main`, 폴더는 `/(root)`로 선택하고 저장합니다.
5. 표시되는 HTTPS URL로 접속합니다.

## OpenStreetMap 관련 참고
`file://`로 직접 열면 브라우저의 출처/Referer 처리와 타일 서버 정책 때문에 지도가 정상 표시되지 않을 수 있습니다. HTTPS로 호스팅하면 일반적으로 웹 출처가 전달되어 문제가 줄어듭니다. 타일 제공자는 사용 정책을 준수해야 합니다.
